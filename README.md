# JEPH Bev - Natures Pride

Product website for **JEPH Bev Pvt. Ltd.** (Jaipur), maker of Natures Pride flavoured fruit drinks - scroll-driven 3D-style presentation of the Coco Thunder, Mango, Guava and Mixed Fruit range.

## Tech stack

- HTML, CSS and JavaScript
- Video and poster assets for the scroll-driven product scenes

## Structure

```
index.html   single-page site
index.css    styles
*.mp4, *.webp, *.jpg   hero and product media
```

## Notes

Media assets make up most of the repository size.
